= Eliminar credenciales de NetApp Workload Factory
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Si ya no necesitas un conjunto de credenciales, puedes eliminarlas de Workload Factory. Solo puedes eliminar las credenciales que no estén asociadas con un sistema de archivos FSx for ONTAP.

.Pasos
. Inicia sesión en link:https://console.netapp.com["NetApp Console"^].
. En el menú de NetApp Console, selecciona *Workloads* > *Administration* > *Credentials*.
. En la página *Credentials*, haz lo siguiente:
+
** En la consola de Workload Factory, selecciona el menú de acciones de un conjunto de credenciales y, a continuación, selecciona *Eliminar*. Selecciona *Eliminar* para confirmar.
** En NetApp Console, selecciona el menú de acciones de un conjunto de credenciales y luego selecciona *Delete*. Selecciona *Delete* para confirmar.
