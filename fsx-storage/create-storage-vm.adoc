= Crear una máquina virtual de almacenamiento para un sistema de archivos FSx for ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Crea una máquina virtual de almacenamiento (SVM) para un sistema de archivos FSx for ONTAP para acceder virtualmente a los servicios de almacenamiento y datos para tus cargas de trabajo en NetApp Workload Factory.

.Acerca de esta tarea
Las máquinas virtuales de almacenamiento (SVM) son servidores de archivos aislados que puedes usar para acceder a los datos de cada carga de trabajo en Workload Factory Storage. Cada SVM tiene sus propias credenciales administrativas y endpoints para administrar y acceder a los datos.

Con las SVM, cuando accedes a los datos en FSx for ONTAP, tus clientes y estaciones de trabajo montan un volumen, un recurso compartido CIFS/SMB o un LUN iSCSI alojado por una SVM mediante el endpoint (dirección IP) de la SVM.

.Antes de empezar
Comprueba el número de máquinas virtuales de almacenamiento (SVM) admitidas por sistema de archivos. Consulta link:https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/managing-svms.html#max-svms["Gestión de máquinas virtuales de almacenamiento de FSx for ONTAP"^] en la documentación de AWS para conocer el número máximo de SVM por sistema de archivos.



[[create-a-storage-vm]]
== Crear una máquina virtual de almacenamiento

Puedes crear una máquina virtual de almacenamiento desde la consola de Workload Factory. También puedes usar las siguientes herramientas disponibles en Codebox: la API de REST, CloudFormation y Terraform. link:../admin/use-codebox.html#how-to-use-codebox["Descubre cómo utilizar Codebox para la automatización"^].


NOTE: Al utilizar Terraform desde Codebox, el código que copias o descargas oculta `fsxadmin` y `vsadmin` las contraseñas. Tendrás que volver a introducir las contraseñas cuando ejecutes el código.

.Pasos
. Inicia sesión en link:https://console.netapp.com["NetApp Console"^].
. Selecciona el menú image:workloads-menu-icon.png["El icono del menú hamburguesa se utiliza para ir a Workloads, la opción del menú de Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. En *FSx for ONTAP*, selecciona el menú de acciones del sistema de archivos y, a continuación, selecciona *Manage*.
. En la descripción general del sistema de archivos, en Storage VMs, selecciona *Create storage VM*.
. En la página «Crear máquina virtual de almacenamiento», en la sección «Configuración de la máquina virtual de almacenamiento», introduce los siguientes datos:
+
.. *Nombre*: introduce un nombre para la máquina virtual de almacenamiento.
.. *Credenciales de la máquina virtual de almacenamiento*: introduce una contraseña para el usuario `vsadmin` de esta máquina virtual de almacenamiento o utiliza las credenciales del usuario `fsxadmin` del sistema de archivos.
.. *Estilo de seguridad del volumen raíz*: selecciona el estilo de seguridad del volumen raíz en función del tipo de clientes que accedan a tus datos: UNIX (clientes Linux), NTFS (clientes Windows) o mixto.
.. *Etiquetas*: si lo deseas, puedes añadir hasta 50 etiquetas.


. Selecciona *Crear*.
