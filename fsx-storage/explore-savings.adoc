= Descubre cómo ahorrar con FSx for ONTAP en NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Descubre cuánto puedes ahorrar en tus cargas de trabajo de almacenamiento que usan Amazon Elastic Block Store (EBS), Elastic File System (EFS) y FSx for Windows File Server frente a FSx for NetApp ONTAP.

NetApp Workload Factory incluye una calculadora de ahorro de almacenamiento para comparar los entornos de almacenamiento de Amazon con FSx for ONTAP. Puedes explorar el ahorro tanto si proporcionas tus credenciales de AWS como si no, y personalizar la configuración de tu entorno de almacenamiento. Cuando proporcionas credenciales de AWS, puedes seleccionar una o varias instancias de Amazon Elastic Block Store, por ejemplo, y dejar que Workload Factory haga la comparación automáticamente. Ya sea de forma manual o automática, la calculadora determina qué servicio de almacenamiento ofrece el menor coste para tus necesidades de almacenamiento.

Si la calculadora de almacenamiento determina que la opción de almacenamiento más rentable es FSx for ONTAP, puedes crear o guardar configuraciones de FSx for ONTAP y usar Codebox para generar plantillas de infraestructura como código, independientemente de los permisos que concedas a Workload Factory.



[[calculator-options]]
== Opciones de la calculadora

Hay dos opciones de calculadora disponibles para realizar la comparación de costes entre tus sistemas y FSx for ONTAP: la personalización y la detección automática de tus entornos de almacenamiento de Amazon.

Descubre cómo ahorrar gracias a la personalización: tú proporcionas los parámetros de configuración de un entorno de almacenamiento, incluyendo el caso de uso, la región, el número de volúmenes o sistemas de archivos, la capacidad de almacenamiento, la frecuencia de las instantáneas, la cantidad de datos modificados por instantánea, las IOPS aprovisionadas, el rendimiento y mucho más.

Descubre ahorros para los entornos de almacenamiento detectados: Workload Factory se conecta a tus entornos de almacenamiento de AWS existentes y extrae los detalles a la calculadora para realizar una comparación automática. Tendrás que conceder permisos de automatización para usar el modo automático. Puedes cambiar el caso de uso, pero todos los demás detalles se determinan automáticamente en el cálculo.

Además, puedes link:add-credentials.html["añadir credenciales de AWS"^] para mejorar la precisión del análisis de la calculadora. Selecciona *Calculate savings based on existing resources*. Se te redirigirá a la página Añadir credenciales. Después de añadir credenciales, selecciona los recursos existentes para compararlos con FSx for ONTAP y selecciona *Explore savings*.



[[explore-savings-via-customization]]
== Descubre cómo ahorrar gracias a la personalización

Sigue los pasos que aparecen en la pestaña correspondiente a la opción de almacenamiento que hayas elegido.

[role="tabbed-block"]
====
.Amazon Elastic Block Store (EBS)
--
.Pasos
. Inicia sesión en link:https://console.netapp.com["NetApp Console"^].
. Selecciona el menú image:workloads-menu-icon.png["El icono del menú hamburguesa se utiliza para ir a Workloads, la opción del menú de Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. En *FSx for ONTAP*, selecciona *Explorar ahorros* y, a continuación, selecciona la pestaña *Amazon Elastic Block Store (EBS)*.
. En la calculadora de ahorro de almacenamiento, introduce los siguientes datos:
+
.. *Caso de uso*: obligatorio. Selecciona un caso de uso en el menú desplegable. El caso de uso seleccionado determina las características del sistema de archivos FSx for ONTAP que se utilizarán para la comparación.
.. *Región*: opcional. Selecciona la región para tu configuración de EBS en el menú desplegable.
.. *Seleccionar tipo de volumen EBS*: opcional. Selecciona el tipo de volumen EBS que se utiliza en tu configuración.
.. *Número de volúmenes*: opcional. Introduce el número de volúmenes en tu configuración de EBS.
.. *Capacidad de almacenamiento por volumen (TiB)*: opcional. Introduce la capacidad de almacenamiento por volumen en TiB.
.. *Frecuencia de instantáneas*: opcional. Selecciona la frecuencia de instantáneas para tu configuración de EBS.
.. *Cantidad modificada por instantánea (GiB)*: opcional. Solo para el almacenamiento de instantáneas. Introduce la cantidad modificada por instantánea en GiB.
.. *IOPS aprovisionadas por volumen*: opcional. Para volúmenes gp3, io1 e io2. Introduce las IOPS aprovisionadas por volumen.
.. *Rendimiento (MiB/s)*: opcional. Solo para volúmenes gp3. Introduce el rendimiento en MiB/s por volumen.




--
.Amazon FSx for Windows File Server
--
.Pasos
. Inicia sesión en link:https://console.netapp.com["NetApp Console"^].
. Selecciona el menú image:workloads-menu-icon.png["El icono del menú hamburguesa se utiliza para ir a Workloads, la opción del menú de Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. En *FSx for ONTAP*, selecciona *Explorar ahorros* y, a continuación, selecciona la pestaña *Amazon Elastic Block Store (EBS)*.
. En la calculadora de ahorro de almacenamiento, introduce los siguientes datos:
+
.. *Caso de uso*: obligatorio. Selecciona un caso de uso en el menú desplegable. El caso de uso seleccionado determina las características del sistema de archivos FSx for ONTAP que se utilizarán para la comparación.
.. *Región*: opcional. Selecciona la región para tu configuración de FSx for Windows File Server en el menú desplegable.
.. *Tipo de implementación*: opcional. Selecciona *Una sola zona de disponibilidad* o *Varias zonas de disponibilidad*.
.. *Tipo de almacenamiento*: por defecto, está seleccionado el tipo de almacenamiento SSD.
.. *Capacidad de almacenamiento (TiB)*: opcional. Introduce la capacidad de almacenamiento para la configuración.
.. *Ahorro por deduplicación (%)*: opcional. Introduce el porcentaje de ahorro de capacidad que esperas obtener gracias a la deduplicación.
.. *Frecuencia de las instantáneas*: opcional. Selecciona la frecuencia de las instantáneas para tu configuración.
.. *Cantidad modificada por instantánea (GiB)*: opcional. Solo para el almacenamiento de instantáneas. Introduce la cantidad modificada por instantánea en GiB.
.. *IOPS de SSD asignadas*: opcional. Introduce las IOPS de SSD asignadas.
.. *Rendimiento (MiB/s)*: opcional. Introduce el rendimiento en MiB/s.




--
.Amazon Elastic File System (EFS)
--
.Pasos
. Inicia sesión en link:https://console.netapp.com["NetApp Console"^].
. Selecciona el menú image:workloads-menu-icon.png["El icono del menú hamburguesa se utiliza para ir a Workloads, la opción del menú de Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. En *FSx for ONTAP*, selecciona *Explorar ahorros* y, a continuación, selecciona la pestaña *Amazon Elastic Block Store (EBS)*.
. En la calculadora de ahorro de almacenamiento, introduce los siguientes datos:
+
.. *Caso de uso*: obligatorio. Selecciona un caso de uso en el menú desplegable. El caso de uso seleccionado determina las características del sistema de archivos FSx for ONTAP que se utilizarán para la comparación.
.. *Región*: opcional. Selecciona la región para tu configuración de FSx for Windows File Server en el menú desplegable.
.. *Tipo de sistema de archivos*: opcional. Selecciona *Regional* o *Una zona*.
.. *Capacidad de almacenamiento (TiB)*: opcional. Introduce la capacidad de almacenamiento de la configuración de EFS.
.. *Datos a los que se accede con frecuencia (%)*: opcional. Introduce el porcentaje de datos a los que se accede con frecuencia.
.. *Modo de rendimiento*: opcional. Selecciona *Rendimiento asignado* o *Rendimiento elástico*.
.. *Rendimiento (MiB/s)*: opcional. Introduce el rendimiento en MiB/s.




--

[[explore-savings-for-detected-storage-environments]]
== Explora el ahorro en los entornos de almacenamiento detectados

.Antes de empezar
Para que Workload Factory pueda detectar los entornos de almacenamiento de Amazon Elastic Block Store (EBS), Elastic File System (EFS) y FSx for Windows File Server en tu cuenta de AWS, asegúrate de que link:add-credentials.html["conceder permisos de _visualización, planificación y análisis_"^] en tu cuenta de AWS.


NOTE: Esta opción de la calculadora no admite cálculos para instantáneas de EBS ni copias de sombra de FSx for Windows File Server. Al explorar el ahorro mediante la personalización, puedes proporcionar detalles sobre las instantáneas de EBS y de FSx for Windows File Server.

Sigue los pasos que aparecen en la pestaña correspondiente a la opción de almacenamiento que hayas elegido.

[role="tabbed-block"]
====
.Amazon Elastic Block Store (EBS)
--
.Pasos
. Inicia sesión en link:https://console.netapp.com["NetApp Console"^].
. Selecciona el menú image:workloads-menu-icon.png["El icono del menú hamburguesa se utiliza para ir a Workloads, la opción del menú de Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. En *FSx for ONTAP*, selecciona *Explorar ahorros* y, a continuación, selecciona la pestaña *Amazon Elastic Block Store (EBS)*.
. En la pestaña *Elastic Block Store (EBS)*, selecciona la(s) instancia(s) que deseas comparar con FSx for ONTAP y selecciona *Explore savings*.
. Aparece la calculadora de ahorro de almacenamiento. Las siguientes características del sistema de almacenamiento aparecen ya rellenadas en función de las instancias que hayas seleccionado:
+
.. *Caso de uso*: el caso de uso de tu configuración. Puedes cambiar el caso de uso si es necesario.
.. *Volúmenes seleccionados*: el número de volúmenes en la configuración de EBS
.. *Cantidad total de almacenamiento (TiB)*: la cantidad de almacenamiento por volumen en TiB
.. *IOPS totales aprovisionadas*: para volúmenes gp3, io1 e io2
.. *Rendimiento total (MiB/s)*: solo para volúmenes gp3




--
.Amazon FSx for Windows File Server
--
.Pasos
. Inicia sesión en link:https://console.netapp.com["NetApp Console"^].
. Selecciona el menú image:workloads-menu-icon.png["El icono del menú hamburguesa se utiliza para ir a Workloads, la opción del menú de Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. En *FSx for ONTAP*, selecciona *Explorar ahorros* y luego selecciona la pestaña *Amazon FSx for Windows File Server*.
. En la pestaña *Amazon FSx for Windows File Server*, selecciona la(s) instancia(s) que quieres comparar con FSx for ONTAP y selecciona *Explorar ahorros*.
. Aparece la calculadora de ahorro de almacenamiento. Las siguientes características del sistema de almacenamiento se rellenan automáticamente en función del tipo de implementación de las instancias que hayas seleccionado:
+
.. *Caso de uso*: el caso de uso de tu configuración. Puedes cambiar el caso de uso si es necesario.
.. *Sistemas de archivos seleccionados*
.. *Capacidad total de almacenamiento (TiB)*
.. *IOPS de SSD aprovisionadas*
.. *Rendimiento (MiB/s)*




--
.Amazon Elastic File System (EFS)
--
.Pasos
. Inicia sesión en link:https://console.netapp.com["NetApp Console"^].
. Selecciona el menú image:workloads-menu-icon.png["El icono del menú hamburguesa se utiliza para ir a Workloads, la opción del menú de Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. En *FSx for ONTAP*, selecciona *Explorar ahorros* y luego selecciona la pestaña *Amazon Elastic File System (EFS)*.
. En la pestaña *Elastic File System (EFS)*, selecciona la(s) instancia(s) que deseas comparar con FSx for ONTAP y selecciona *Explorar ahorros*.
. Aparece la calculadora de ahorro de almacenamiento. Las siguientes características del sistema de almacenamiento aparecen ya rellenadas en función de las instancias que hayas seleccionado:
+
.. *Caso de uso*: el caso de uso de tu configuración. Puedes cambiar el caso de uso si es necesario.
.. *Total de sistemas de archivos*
.. *Capacidad total de almacenamiento (TiB)*
.. *Rendimiento total aprovisionado (MiB/s)*
.. *Rendimiento elástico total - lectura (GiB)*
.. *Rendimiento elástico total - escritura (GiB)*

== Implementa sistemas de archivos FSx for ONTAP

Si quieres cambiar a FSx for ONTAP para ahorrar costes, selecciona *Crear* para crear los sistemas de archivos directamente desde el asistente «Crear un sistema de archivos FSx for ONTAP» o selecciona *Guardar* para guardar las configuraciones recomendadas para más adelante.

Métodos de implementación:: Con los permisos de _creación de sistemas de archivos_, puedes implementar el sistema de archivos FSx for ONTAP directamente desde Workload Factory. También puedes copiar el contenido de la ventana de Codebox e implementar el sistema utilizando uno de los métodos de Codebox.
+
--
Con los permisos de _visualización, planificación y análisis_, puedes copiar el contenido de la ventana de Codebox e implementar el sistema de archivos FSx for ONTAP mediante uno de los métodos de Codebox.
