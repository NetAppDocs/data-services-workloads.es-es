= Inicio rápido para Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Empieza a usar Google Cloud NetApp Volumes configurando Google Cloud y luego creando un sistema.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:set-up.html["Configura Google Cloud NetApp Volumes"]
[role="quick-margin-para"]
En Google, crea una cuenta de servicio.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] link:add-roles.html["Asignar funciones"]
[role="quick-margin-para"]
Para empezar a trabajar con Google Cloud NetApp Volumes, debes tener los permisos adecuados y tener asignado el rol de administrador de Google Cloud NetApp Volumes o el de visor de Google Cloud NetApp.

[role="quick-margin-para"]
image:role_gcnv.png["Una captura de pantalla del rol de Google Cloud NetApp Volumes."]

[role="quick-margin-para"]
Desde NetApp Console, asigna los roles adecuados a los miembros.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] link:create-discover-systems.html["Agregar un sistema"]
[role="quick-margin-para"]
En NetApp Console, haz clic en *Add System*, luego en *Google Cloud Platform*, después en *Google Cloud NetApp Volumes* y, por último, en *Discover*. Introduce los datos de la cuenta de servicio y del proyecto de Google Cloud.
