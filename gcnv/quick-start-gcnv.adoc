= Inicio rápido para Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Empieza a usar Google Cloud NetApp Volumes asignando tu rol en NetApp Console, añadiendo credenciales e incorporando un sistema.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:../gcnv/add-roles.html["Asignar funciones"]
[role="quick-margin-para"]
Desde NetApp Console, asigna los roles adecuados a los miembros.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html["Añade credenciales"]
[role="quick-margin-para"]
En NetApp Console, añade las credenciales de Google Cloud NetApp Volumes.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] link:../gcnv/create-discover-systems.html["Agregar un sistema"]
[role="quick-margin-para"]
En NetApp Console, añade un sistema utilizando las credenciales. Si lo deseas, selecciona una región.
