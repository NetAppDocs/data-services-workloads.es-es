= Implementa el sistema de archivos FSx para ONTAP recomendado
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Una vez que hayas comprobado que el sistema de archivos FSx for ONTAP recomendado (o varios sistemas de archivos en algunos casos) se ajusta exactamente a tus necesidades, puedes utilizar Workload Factory para implementar el sistema en tu entorno de AWS.

Sigue las instrucciones de link:../fsx-storage/create-discover-systems.html["Crear un sistema de archivos FSx para ONTAP en NetApp Workload Factory"^] para implementar el sistema de archivos FSx for ONTAP según la configuración recomendada por Workload Factory. Puedes usar los pasos de *Advanced create* de las instrucciones para personalizar por completo el sistema de archivos.
