= Inicio rápido para Oracle Cloud Infrastructure NetApp Storage Service en NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Empieza a usar Oracle Cloud Infrastructure NetApp Storage Service (OCI NSS) añadiendo credenciales y permisos, creando un enlace si hace falta y creando o detectando un sistema de almacenamiento.

Sigue estos pasos para empezar.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] Agrega credenciales y permisos
[role="quick-margin-para"]
link:add-credentials.html["Agregar credenciales a una cuenta"]. Esto incluye seleccionar las capacidades de la carga de trabajo y crear las políticas de IAM para los permisos necesarios.

[role="quick-margin-para"]
Selecciona la política de permisos predeterminada link:permissions-oci.html["visión, planificación y análisis"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] Crear un enlace
[role="quick-margin-para"]
Este paso es opcional. Para realizar algunas tareas de gestión desde la NetApp Console, necesitas un enlace de NetApp Workload Factory. Un _enlace_ aprovecha OCI Functions para crear una relación de confianza y conectividad con tus sistemas OCI NSS.

[role="quick-margin-list"]
* link:../setup/links-overview.html["Descubre cuándo se necesita un agente o un enlace de Console para la gestión de OCI NSS"]
* link:create-link.html["Aprende a crear un enlace"^]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] Descubre o añade un sistema OCI NetApp Storage Service
[role="quick-margin-para"]
Encontrarás un grupo de almacenamiento para empezar a gestionar tus recursos OCI NSS en Workload Factory. En link:https://console.netapp.com["NetApp Console"^], selecciona *Almacenamiento*, luego *Gestión* y, a continuación, *Discoverable systems*. link:create-discover-systems.html["Descubre cómo descubrir un sistema de almacenamiento OCI NSS"].

.Qué sigue
Una vez que tengas un grupo de almacenamiento en tu inventario de almacenamiento, podrás empezar a gestionar tus recursos de OCI NSS.
